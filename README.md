# Device Telemetry Dashboard

A real-time dashboard that shows live readings from simulated devices
(temperature, speed, status), built with React and TypeScript.

## Features (planned)
- TypeScript device simulator that generates realistic fake readings
- Live dashboard with charts and alerts
- Typed REST API client
- Tests with Vitest and React Testing Library

## Tech
React, TypeScript, Vite, Vitest
